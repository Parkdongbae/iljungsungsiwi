# 일성정시의 3D

세종 19년(1437)에 만든 주야 겸용 천문시계 일성정시의(日星定時儀)를 『세종실록』 치수로 3D로 조립해 보고, 낮에는 해로, 밤에는 별로 시각을 재 보는 교육용 웹앱입니다. 대상은 중학생입니다.

- 바로 쓰기: `index.html` 한 파일(GitHub Pages로 배포). 지도 그림과 글꼴만 인터넷이 필요합니다.
- 자매 앱: [앙부일구 3D](https://github.com/Parkdongbae/angbuilgu) — 같은 화면 구성을 쓰며, 기획 문서(PRD, 계산 규칙 명세서, 화면 흐름, 콘텐츠 스키마, 게이미피케이션, MVP 범위)는 그 저장소의 [docs](https://github.com/Parkdongbae/angbuilgu/tree/main/docs) 에 있습니다.

## v2에서 바뀐 것 (2026-11-23)

- 탭을 번호 단계로: ① 내 위치 → ② 만들기 → ③ 낮에 재기 → ④ 밤에 재기 → ⑤ 시계와 차이 → ⑥ 문제 풀기, 이전/다음 버튼
- 단계마다 「이번 단계 할 일」 한 줄, 해내면 ✓
- 시간 막대는 기본 6개 조작만, 나머지(날짜·하루 전후·빠르기·남중·한밤)는 「자세히」
- 설정 창(⚙): 테마, 글자 크기, 시간 막대, 효과음, 기기 종류, 학교 위치 자료, 내 기록
- 심화 내용은 「더 알아보기」로 접음
- 도장 6개, 문제 최고 점수 저장, 첫 방문 안내와 도움말(?)
- 고친 버그: 문제 「계형을 직접 맞춰 보기」(2026-06-10 15:20, 경복궁)의 정답이 신시(申時)로 잘못되어 있던 것을 미시(未時)로 바로잡음(진태양시 14:48). 해설의 오타 「一 시」도 수정
- 배포본에만 있던 지도 타일 수정(Esri → OpenStreetMap 순서로 시도)을 소스 `place.js` 에 반영

천문 계산과 3D 모델은 그대로입니다. 기록은 기기(localStorage)에만 저장합니다.

## 폴더

```
index.html          배포 파일 (빌드 결과)
src/
  template.html     본문
  app.js            화면, 시각 읽기, 조립 단계, 문제
  astro.js          천문 계산(태양·별 위치, 균시차, 백각 표기)
  model.js          3D 모델과 치수
  place.js          위치 검색, 지도
  geo.js, stars.js  시군구·학교 위치, 별 자료
  ang.css           기본 스타일 (앙부일구 base.css 와 같음)
  shell.css, shell.js  겉틀: 단계·할 일·설정 창·도움말·도장 (앙부일구와 같은 파일)
  build.mjs         esbuild 로 묶어 ../index.html 생성
  test.mjs          계산 오차 확인용 스크립트
```

## 빌드

```powershell
cd src; npm install
```

```powershell
cd src; node build.mjs
```

`shell.css`, `shell.js` 를 고치면 앙부일구 저장소의 같은 파일에도 복사합니다.

## 알려진 문제

앙부일구 저장소의 [계산 규칙 명세서](https://github.com/Parkdongbae/angbuilgu/blob/main/docs/01-핵심로직-계산규칙-명세서.md) 부록 A에 정리되어 있습니다. 아직 고치지 않은 것:
- 「낮에 재기」의 100각 표가 실제 판정과 칸 순서가 다름(짧은 1분 칸의 위치)
- 문제 5번 정답(30도)과 「밤에 재기」 패널 표시(31도)가 다름
- 동짓날 0시부터 동지 순간까지 성구환 보정이 약 3분 어긋남

## 검증 (2026-11-23, 로컬 브라우저)

확인한 것: 데스크톱·휴대폰 세로(375px)에서 열림, 콘솔 오류 없음, 위치 선택, 조립 끝까지 진행, 한밤 이동, 설정 창, 문제 10문항 풀이와 기록 저장, v1 본문의 id·data 속성 보존.

확인하지 못한 것: 실제 교실 사용성, Safari·Firefox·실기기, 온라인 지도 타일과 나이스 검색의 네트워크 동작, 효과음.
